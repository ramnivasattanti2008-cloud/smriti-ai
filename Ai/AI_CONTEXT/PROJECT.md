# SMRITI AI

## SIH Problem

SIH26003

AI-Based Cognitive Gaming and Memory Assistance Platform for Elderly Dementia Patients in the North Eastern Region.

## Product Name

SMRITI AI

## Tagline

An AI-Powered Cognitive Companion for Dignified Aging.

## Main Users

1. Elder
2. Caregiver
3. Health Worker

## Main Features

1. Cognitive games
2. Adaptive difficulty
3. Personal memories
4. Voice assistant
5. Daily routines
6. Reminders
7. Caregiver dashboard
8. Health-worker dashboard
9. Regional languages
10. Cultural content
11. Offline functionality
12. Analytics
13. Demo mode

## Adaptive Cognitive Engine

The system should use:

- Accuracy
- Response time
- Mistakes
- Completion rate
- Difficulty level
- Recent activity

to personalize future activities.

The system can recommend:

- Next cognitive activity
- Difficulty level
- Personalized content
- Engagement activities

## Important Medical Requirement

SMRITI AI is NOT a medical diagnosis system.

The application must never claim that game performance diagnoses dementia or any other medical condition.

Use terms such as:

- Cognitive Activity
- Game Performance
- Engagement
- Response Time
- Activity Trend

instead of medical diagnosis scores.

## Target Device

Tablet-first.

The elderly interface should have:

- Large buttons
- Large text
- High contrast
- Simple navigation
- Large touch targets
- Minimal cognitive load
- Voice support

## Security

Never expose API keys.

Never hardcode passwords or secrets.

Use environment variables.

Use proper authentication and authorization.

## Offline Requirement

Core cognitive games should work without internet.

Game results should be stored locally.

Data should synchronize when internet connectivity returns.

## SIH Goal

Create a polished, reliable, accessible and innovative prototype suitable for Smart India Hackathon evaluation.

The application should demonstrate:

- Real AI usage
- Personalization
- Accessibility
- Offline capability
- Meaningful analytics
- Strong UI/UX
- Reliable implementation
- Clear social impact
